# montage-core

**A Chinese-first, agent-driven AI video production system** (independent project, original code, MIT).

> The goal: turn "AI video production" into a governable, extensible pipeline with real shot language —
> the agent reads pipeline configs, calls registry tools, and advances stage by stage through checkpoint gates;
> prompt engineering is treated as a knowledge asset (Chinese narrative semantics + English quality-layer constants).

## Design Principles

1. **Agent as director, code as studio**: orchestration and creative decisions are config-driven via `docs/AGENT_GUIDE.md` and `montage/pipelines.py`; Python provides tools and state management only.
2. **Artifacts are contracts**: every stage emits a schema-validated JSON artifact (`artifacts/`); schema validation failure means failure.
3. **Registry + selectors**: adding a provider = writing one `BaseTool` subclass into `providers/`; selectors auto-discover it.
4. **Fully auditable**: cost ledger (estimate → settlement), decision log (append-only, latest wins), checkpoint history archiving.
5. **Prompt engineering as an asset**: `prompt_library/` (170 structured Chinese entries in 12 categories, incl. 12 public-domain screenplay templates and character/tone anchors) + five-layer shot language + first-frame/video dual prompts + compression budgets + vocabulary fallback injection.

## Capabilities

- **Pipeline engine**: research → proposal → script → scene_plan → assets → compose → publish, with gate approvals, history archiving, artifact validation, cost ledger and decision log; **3 pipelines** (cinematic / documentary / clip_factory).
- **Contract governance**: an independent gates layer validates that declared artifacts exist and pass JSON Schema when a checkpoint completes (relax with `MONTAGE_RELAX_GATES=1`); `check --caps` capability-family allowlists; budget ceilings with append-only settlement reconciliation; selector route caching; atomic artifact writes.
- **Compose**: `compose_planner` writes per-shot transitions/LUT/subtitle slots as `compose_plan` and compiles it into `edit_decisions` (assemble reads **only** the latter); FFmpeg concatenation / **xfade transitions (cut/crossfade/fade_black/wipe/negative gap)** / **Ken Burns camera moves on stills (zoompan)** / cropping / subtitle burn-in (incl. ASS styling) / narration+BGM mixing (assemble defaults to **ducking + loudnorm**) / final assembly / LUT color grading (`apply_lut`) / platform output profiles (`apply_profile`) / narration assembly (plan/assemble_narration).
- **Generation strategy**: `shot_runner` orchestrates character turnarounds → first frame → QC → image-to-video (defaults to `dry_run`; no API call over budget); `asset_quality_gate`, `asset_picker` A/B selection, `generation_cache`, shot-tier cost policy (transition/establishing shots use stills + Ken Burns).
- **Script quality layer**: character cards (`characters[]`) / story beats / character registry in schema; `script_validator` deterministic gates (dialogue budgets per provider duration grids, Jimeng 5/10s, filmability checks, character-reference consistency); directing manual `docs/DIRECTOR_GUIDE.md`; self-review protocol `docs/REVIEWER.md`.
- **Prompt engineering**: zero-dependency Chinese vocabulary retrieval, per-shot "first-frame image + video motion" dual prompts, deterministic edit/transition advisor, public-domain screenplay template library.
- **Style playbooks** (`montage/playbooks/`, zero-dependency Python dicts): Chinese elegance / cyberpunk / Japanese healing / documentary restraint / shonen anime / manga panel / spoken explainers (7 books), locked at proposal and carried through the whole film.
- **Open asset library** (`assets/`): SFX index (Sonniss GDC), music index (FreePD/incompetech, BPM beats), original color LUTs (6 `.cube` files generated by `scripts/make_luts.py`), subtitle font guide (Source Han Sans, OFL); `asset_retriever` zero-dependency retrieval; `ffmpeg_compose` supports `apply_lut` grading and `apply_profile` platform outputs.
- **Chinese provider closed loop** (contract tiers labeled; works once keys are configured):
  - Agnes: image / video / voice closed loop (`AGNES_API_KEY` / `AGNES_CN_API_KEY`)
  - Jimeng (Volcengine): image `jimeng_t2i_v40`, video 3.0 family (HMAC V4 signing, `VOLC_ACCESSKEY/SECRETKEY`)
  - **Wanxiang** (DashScope): image `wan2.5-t2i` / video `wan2.1-t2v` (async task mode, `DASHSCOPE_API_KEY`)
  - **Zhipu CogVideoX**: video generation (`ZHIPU_API_KEY`)
  - **Kling** (Kuaishou): image/video generation (`KLING_API_KEY`, pending live verification)
  - **Hunyuan** (Tencent): video generation (`HUNYUAN_API_KEY`, pending live verification)
  - DashScope: word-level timestamp ASR (`DASHSCOPE_API_KEY`)
  - Doubao: TTS with char-level timestamps (`DOUBAO_SPEECH_API_KEY`); Seed-Audio music generation (pending)
  - Edge TTS: free Chinese TTS (`pip install edge-tts`, no key needed)
  - **Piper**: offline local TTS (`pip install piper-tts` + Chinese model, commercial-use OK)
- **Assets & delivery**: `stock_retriever` stock search (wikimedia free / pixabay / pexels), `downloader`, `export_bundle` project export (zip + manifest), `screen_recorder`.
- **Finishing**: `produce` runs finish (explicit LUT / platform profile / 2s title card / subtitle bypass) and `release_pack` (cover frame extraction + 3-platform blurb templates + `publish_log`) after assembly, then zips.
- **Web dashboard**: project list, stage progress, artifact browsing, budget, decisions, one-click checkpoint writes; the 7-stage film plays `renders/final.mp4` (separate from AutoEditor); `--retry` re-runs specified shots after confirmation.

## Quick Start

```bash
cd montage-core
copy .env.example .env            # Windows PowerShell; on bash: cp .env.example .env
# Edit the repo-root .env with your VOLC_ACCESSKEY/SECRETKEY etc. (empty = not configured; never git add it)
python -m montage doctor          # see which providers become available (importing tools directly skips .env)
python scripts/minitest.py        # needs pip install -e . (core dependency: jsonschema)
python -m montage init <id> --title "Project Name"
python -m montage run <project_dir> prompt_library_retriever --input inputs.json
python -m montage produce <project_dir>   # with clips on disk: soundtrack → assemble → finish → release pack → zip
python -m montage produce <project_dir> --retry sh01 --yes  # re-run failed shots (cost previewed first)
python -m montage auto_edit <dir> --video raw.mp4 --style documentary  # quick edit (skips the 7 stages)
python -m montage webui --port 8399  # launch dashboard (needs pip install "montage-core[webui]")
python examples/pipeline_flow.py     # full-flow demo (local deterministic tools, no API keys)
python examples/zero_key_edit.py     # zero-key local editing (needs MONTAGE_REAL_FFMPEG=1)
python scripts/make_luts.py          # regenerate the original LUTs (assets/luts/*.cube)
python assets/scripts/fetch_assets.py --list   # list downloadable SFX/music/fonts
```

Install: `pip install -e .` (core dependency: `jsonschema` only). Requires `ffmpeg`/`ffprobe` on PATH. Web dashboard: `pip install "montage-core[webui]"`.

## Directory Structure

```
montage-core/
├── montage/
│   ├── toolbase.py          # BaseTool contract (ToolResult / status / cost estimate / input validation)
│   ├── registry.py          # tool registry + capability selectors + capability menu
│   ├── schemas.py           # canonical artifact JSON Schemas (loose; script includes characters/beats)
│   ├── pipelines.py         # cinematic / documentary / clip_factory pipeline configs
│   ├── cli.py               # doctor/tools/init/status/check/run/auto_edit/webui
│   ├── engine/              # stages / artifacts / budget / decisions / gates / runtime
│   ├── tools/               # vocabulary retrieval / visual prompts / edit advisor / script validation
│   ├── providers/           # agnes / jimeng / dashscope / doubao / edge_tts / selectors
│   ├── playbooks/           # 7 original style playbooks (Python dicts, no YAML)
│   ├── compose/             # FFmpeg compose + narration assembly + LUT grading + platform profiles
│   └── webui/               # FastAPI service + single-page dashboard
├── lib/                     # deterministic knowledge modules (prompt retrieval, shot prompt assembly, asset catalog)
├── prompt_library/          # 170 structured Chinese entries (12 categories; MIT/public domain, see CREDITS.md)
├── assets/                  # open media assets (SFX/music/LUT/font indexes + licenses, see README.md)
├── docs/                    # AGENT_GUIDE / DIRECTOR_GUIDE / REVIEWER / skills / PROGRESS
├── examples/                # pipeline_flow / zero_key_edit
├── scripts/                 # minitest / make_luts (original LUT generation)
└── tests/                   # see docs/PROGRESS.md for counts
```

## Contract Tiers (Provider Interfaces)

- **Wired**: callable per official contracts once keys are set — Jimeng image/video, Wanxiang image/video, CogVideoX, Agnes image, DashScope ASR, Doubao TTS, Edge TTS.
- **Pending live verification**: implemented, needs real keys — Kling image/video, Hunyuan video, Agnes video/voice, Doubao Seed-Audio, talking_head / lip_sync.
- **Interface only**: placeholder, no provider yet — `music_gen`.

No Remotion / HyperFrames for now: the product assembles AI clips (FFmpeg covers it); a Node runtime would be a separate repo; copying the OpenMontage composer would trigger AGPL.

## Ecosystem

Two independently usable libraries were extracted along the dependency direction (behavior mirrors the corresponding layers of this repo):

- **[montage-providers](https://github.com/1084669403/montage-providers)** — unified SDK for Chinese video/image/TTS APIs: capability-table routing, per-API "prompt dialects", golden-fixture contract tests; zero third-party dependencies.
- **[montage-composer](https://github.com/1084669403/montage-composer)** — pure-FFmpeg compose toolkit: xfade transition chains, Ken Burns, LUT grading (6 original LUTs), subtitles, ducked audio mixing, platform output profiles; zero third-party dependencies.
