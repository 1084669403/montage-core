# 参考片怎么用

参考片只服务三件事：结构、节奏、镜头比例。禁止逐镜复刻他人画面、对白或商标。

做法：

1. 自己看片，记下：开场钩子、中段升级、落点、平均镜头时长、是否竖屏。
2. 把观察写进 `research_brief.references[].note`（可附公开 URL，不要下载受版权保护的素材当素材源）。
3. `proposal_packet.concept` 用自己的概念句，不要写「做成某某广告那样」。
4. 转场与 LUT 从本仓库 `edit_advisor` / `assets/luts` 选，不从参考片抽滤镜文件。

没有 `web_search` 工具。检索公开资料用你自己的浏览器，再手工写入 brief。
