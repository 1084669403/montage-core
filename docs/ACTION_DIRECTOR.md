# ACTION_DIRECTOR — 动作指导执法手册

> 动作指导是协议角色（Agent 扮演），执法项与审读范围见 [ROLES.md](ROLES.md)。
> 确定性工具：schema 校验、`script_validator`（可拍性）、VLM 关键帧抽检。

## 审读范围

- `await_shots`（点位一）：subjects.action 全字段 + 武术段。
- `await_final_prompt`（点位二）：子 Agent 首审（仅一次，`phase=first_pass`）→ 换帽复审。
- `await_clips`：VLM 结果+关键帧抽帧读静态形态；连续动作完整性由用户停点终审。

## 三查（普通动作）

1. **verb 可拍性**：心理不可拍、动作可拍——"愤怒"→"摔门"；verb 必须是可见物理动作。
2. **manner 匹配情绪**：方式状语与角色当下情绪/台词语气一致。
3. **body_part+contact 具体性**：接触类动作必须写清身体部位与接触物
   （"右手抓住衣领"），缺 contact 的打斗动作=模型上限高发区。

## 武术识别与审法

- **识别标志词**：拳/掌/腿/踢/旋/格挡/闪身/剑/刀/枪（械）/招式/内力/轻功等。
- **审法**：招式节奏 vs 镜头时长（一招 1-2s，10s 镜最多 3-4 招）；
  **动作-对白互斥**（同镜密集对白+密集动作→拆镜）；
  运动模糊与景别承接（快招配 close/medium，大走位配 wide）。

## 执法项

1. **单镜单动作（①）**：一镜只写一个主动作；"抓住衣领并夺枪再转身"必须拆。
2. **动作-对白互斥**：见上。
3. **重抽前置**：`--retry <shot_id>` 前走六步归因（[ROLES.md](ROLES.md) 第 6 节）。
4. **简化动作 + 特效补偿（P0-8）**：AI 生成复杂动作是模型上限高发区——复杂动作
   三出路：**拆镜 > 简化 verb + vfx 补偿 > 换供应商**。简化后由特效指导的
   `vfx[]`（速度线/残影/光效/慢镜）+ `audio_prompt.sfx`（冲击音）补视觉冲击。
   写法示范："挥剑"（verb）+ prompt 层 vfx"剑锋扫过处迸出青色弧光"，
   替代"回旋三连斩翻身后空劈"。
5. **动作返修通知特效帽（双角色闭环）**：动作简化即特效锚点变更——返修后
   必须让特效指导重新对账 `vfx[]`（onset 对准新动作点），防特效落空。

## 字段编辑纪律

- **action 四字段（verb/manner/body_part/contact）整组写**（V27，同美术指导）。
- 镜头级修复走 `bible.scenes[].shots[]` → 先重编译（V23/V29 直读形态）再 `--resume`。
- 每轮 REVISE 必须 `review_logger record`（role=action_director，返修轮 phase=revise）；
  轮次 ≤4（点位一+点位二共用）。
